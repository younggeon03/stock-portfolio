## 1. 한눈에

스프링부트 서버 **하나**가 증권사 두 곳과 공시처 두 곳, 클로드를 대신 불러 화면에 JSON 으로 건넵니다.
브라우저는 바깥 API 를 직접 부르지 않습니다. 키가 브라우저에 있으면 F12 로 보이기 때문입니다.

```
 브라우저 (HTML·CSS·JS, 빌드 도구 없음)
    │  fetch · JSON
    ▼
┌──────────────── 스프링부트 :8080 (jar 하나) ────────────────┐
│  web (컨트롤러 16개, 주소 38개)                               │
│    │                                                          │
│  service ── 합산·비중·변동성·차트 / 기업분석 / 스크린샷 / 종목검색 │
│    │                                                          │
│  brokerage (증권사 공통 규약)     external (바깥과 말하는 코드)   │
│    ├ 토스 ─────────────────────────► 토스증권 Open API (시세·환율·잔고)
│    ├ 나무 ─────────────────────────► 나무증권 NAMUH PLUG (잔고)
│    └ 직접 입력 ─┐                   DART · SEC EDGAR (공시 재무, 0원)

│                 │                   Claude API (분석·스크린샷·뉴스, 유료)
│  domain (JPA)   │                   구글 뉴스 RSS (0원)
```

**내 보유종목은 저장하지 않습니다.** 매번 증권사에서 받아옵니다. 저장하는 건 토큰, 직접 입력한 종목, 분석 결과, 종목·공시 번호 매핑, 그리고 공개 자료인 기관 13F 보유입니다.

## 2. 서버 구성

### 프로세스

`java -jar portfolio-0.0.1-SNAPSHOT.jar` 한 개입니다. 포트를 두 개 엽니다.

| 포트 | 무엇 | 누가 부르나 |
|---|---|---|
| 8080 | API 와 정적 파일(화면) | 브라우저 |
| 8081 | 관리 주소: `/actuator/health`(`/liveness`, `/readiness`), `/actuator/prometheus` | 자동 배포의 헬스체크, Prometheus. **바깥에 열지 않음** |

readiness 는 DB 연결까지 봅니다. DB 가 죽었는데 "준비됨" 이라고 하면 자동 배포가 깨진 버전을 통과시키기 때문입니다.
화면 파일도 jar 안에 들어가므로 css 만 고쳐도 다시 빌드해야 합니다.

### 설정이 들어오는 길

```
.env ──(EnvFileLoader, 앱 시작 직전)──► System Property
                                            │
application.yml 의 ${TOSS_CLIENT_ID:} 같은 자리 ◄─┘   (OS 환경변수도 같은 자리로 들어옴)
        │
        ▼
@ConfigurationProperties 레코드 (TossApiProperties, NamuhApiProperties, AnthropicProperties, DartProperties, EdgarProperties)
```

- `.env` 가 없어도 앱은 뜹니다. 도커나 서버에서는 OS 환경변수로 넣으면 됩니다
- 키가 비어 있으면 그 기능을 **실제로 부르는 순간** 무엇을 채워야 하는지 알려주는 에러가 납니다. 앱 기동은 막지 않습니다
- DART 키나 `SEC_USER_AGENT` 가 없으면 공시 재무를 건너뛰고 분석은 예전처럼 웹 조사로 돕니다

### 바깥 연결

연결마다 `RestClient` 빈을 따로 둡니다. 기본 주소와 헤더가 달라서입니다.

| 빈 | 설정 클래스 | 상대 |
|---|---|---|
| `tossRestClient` | `TossRestClientConfig` | openapi.tossinvest.com |
| `namuhRestClient` | `NamuhRestClientConfig` | api.nhplug.com:8443 |
| `dartRestClient` | `DartRestClientConfig` | opendart.fss.or.kr |
| `edgarRestClient` | `EdgarRestClientConfig` | data.sec.gov·www.sec.gov (User-Agent 필수). 공시 재무와 13F 가 같이 씀 |
| `publicDataRestClient` | `PublicDataRestClientConfig` | 구글 뉴스 RSS, 공인 IP 확인 등 |
| (클래스 안에서 만듦) | `OpenFigiClient` | api.openfigi.com. 키가 있으면 헤더를 붙여야 해서 따로 둠 |

클로드는 RestClient 가 아니라 Anthropic Java SDK(`AnthropicClientProvider`)로 부릅니다.

### 스레드

요청은 톰캣 스레드에서 처리합니다. 따로 만든 스레드는 둘입니다.

| 스레드 | 무엇 | 왜 하나뿐인가 |
|---|---|---|
| 기업분석 (`CompanyAnalysisService`) | 클로드 호출 | 동시에 여러 건이 돌면 비용이 배로 나감 |
| `13f-sync` (`ThirteenFSyncService`) | 13F 받기·티커 찾기 | 아침 스케줄과 수동 실행이 겹치면 같은 접수를 두 번 넣음 |

스케줄러(`@Scheduled`, `SchedulingConfig`)는 13F 받기 하나입니다. 매일 07:00(한국 시간). 앱이 꺼져 있던 날은 다음에 켰을 때 따라잡습니다(받은 접수번호는 건너뛰므로).

### 누가 무엇을 보나 (`SecurityConfig`)

| 영역 | 주소 | 로그인 |
|---|---|---|
| 공개 | `/`, `/index.html`, `/public/**`, `GET /api/institutions/**`(단 `/sync` 제외), `/api/public/**`, `/feeds/**` | 없음 |
| 관리 | 8081 의 `/actuator/health/**`, `/actuator/prometheus` | 없음 (포트를 바깥에 안 엶) |
| 내 영역 | 그 밖의 전부: 잔고·증권사·분석·스크린샷·뉴스·Swagger·13F 수동 받기 | 필요 |

- 계정은 환경변수의 하나뿐입니다(`OWNER_USERNAME`·`OWNER_PASSWORD`). 회원 테이블이 없습니다. 여러 사람이 계좌를 연결하는 서비스가 아니라서입니다 → [결정기록 004](결정기록.md#004-증권사-로그인을-포기하고-스크린샷으로-우회한다)
- **비밀번호가 비면 전부 엽니다**(내 PC 개발용, 기동 경고). 서버에서는 반드시 넣습니다
- 로그인은 폼 + 세션 쿠키(12시간, `SameSite=Strict`, `HttpOnly`). 세션은 메모리에만 있어 재시작하면 다시 로그인합니다
- CSRF: 서버가 `XSRF-TOKEN` 쿠키를 내리고 화면의 `apiFetch` 가 POST·PUT·DELETE 마다 `X-XSRF-TOKEN` 헤더로 돌려보냅니다. 토큰 없는 POST 는 403
- 로그인 안 된 요청: API(`/api/**`)는 401, 화면은 로그인 페이지로. `apiFetch` 가 401 을 받으면 로그인 페이지로 보냅니다

### 에러가 응답이 되는 길

`GlobalExceptionHandler` 가 예외를 모두 `{ "error": "사람이 읽을 한국어 문장" }` 으로 바꿉니다.

| 예외 | 상태 | 예 |
|---|---|---|
| `AppException` | 502 | 바깥 API 실패. 토스 403 이면 지금 공인 IP 까지 적어 줌 |
| `IllegalArgumentException` | 400 | 보유하지 않은 종목을 분석하려 함 |
| 읽을 수 없는 요청 본문 | 400 | |
| 없는 주소 | 404 | |

```

  │
service/           (7)  합산(UnifiedPortfolioService) · 변동성·차트(StockAnalytics)
  service/analysis/  (6) 기업분석: 사실 모으기 → 프롬프트 조립 → 백그라운드 실행 → 저장
  service/importing/ (5) 스크린샷 읽기, 값 다듬기, 직접 입력 저장
  service/symbol/    (2) 이름 → 종목코드 (오타 허용 검색)
  service/institution/ (2) 받아 둔 13F 를 화면용으로 (기관 목록, 분기별 보유·비중, 분기 변화, 여러 기관 동시 매수)
  │

  │

  toss/ (7+dto 11)   토큰, 잔고, 시세, 일봉, 환율, 종목정보

  dart/ (7)          한국 공시 재무
  edgar/ (4)         미국 공시 재무

  anthropic/ (6)     기업분석·스크린샷 호출
  news/ (3)          뉴스 목록(RSS)과 뉴스 인사이트
  auth/ (3)          토큰 저장소 (메모리 + MySQL), 토큰 암호화

```

위 계층은 아래를 알지만 아래는 위를 모릅니다. `service` 는 `web` 을 모르고, 합산 코드는 어느 증권사인지 모릅니다.

### 증권사 어댑터

```java
public interface BrokerageClient {
    Broker broker();                                    // 이름·식별자
    boolean isConfigured();                             // 키가 채워졌나
    List<BrokerageHolding> holdings(String ownerKey);   // 보유종목
}
```

| 구현 | 어디서 가져오나 |
|---|---|
| `TossBrokerageClient` | 토스 계좌 |
| `NamuhBrokerageClient` | 나무 계좌 (국내·해외를 따로 불러 합침) |
| `ManualBrokerageClient` | MySQL `manual_holding` (스크린샷·직접 입력) |

증권사를 늘리려면 이 인터페이스를 구현하고 `@Component` 만 붙입니다. 스프링이 `List<BrokerageClient>` 에 끼워 넣으므로 **비중·변동성·차트·기업분석 코드는 한 줄도 안 고칩니다.**
**주문 메서드는 없습니다.** 부를 대상 자체가 없습니다 → [결정기록 001](결정기록.md#001-주문-api를-만들지-않는다)

## 4. 요청이 흐르는 길

### 표를 그릴 때

```
GET /api/portfolio/unified?scope=ALL
  → UnifiedPortfolioController → UnifiedPortfolioService
      → BrokerageClient 구현 전부에게 holdings()     ← 한 곳이 실패해도 나머지는 보임
      → 같은 종목을 한 줄로 합침 (lots 에 출처 보관)
      → 토스 시세로 현재가 채움                      ← 시세는 토스에서만 (결정기록 002)
      → USD 는 토스 환율로 원화 환산                 ← 실패하면 예외. 1 로 대신하지 않음
      → 평가금액·손익·수익률·비중 계산
  → JSON
```

화면은 이 응답 하나로 표를 그리고, 변동성과 분석 여부는 뒤이어 따로 채웁니다. 표가 먼저 떠야 해서입니다.

### 기업분석을 돌릴 때 (비동기, 유료)

```
POST /api/analysis/{symbol}
  1. 저장된 성공 분석이 있으면 그대로 돌려줌 (0원)
  2. 이미 RUNNING 이면 중복으로 안 부름
  3. 사실 모으기 (톰캣 스레드)
       합산 포트폴리오에서 내 수량·평단가·비중
       토스: 종목정보(ETF·레버리지), 변동성, 60일 고저
       FilingService: 공시 재무 → 최근 4분기·PER·PBR·과거 배수   ← 실패해도 계속
  4. status=RUNNING 저장 후 바로 응답
  5. 분석 스레드: 프롬프트 조립 → Claude(웹검색) → JSON 검증 → MySQL
화면은 3초마다 GET /api/analysis/{symbol} 로 상태를 봄 (NONE / RUNNING / OK / ERROR)
```

재분석이 실패해도 이전에 성공한 분석은 남습니다. `analysis_json` 은 마지막 **성공**, `status`·`last_error` 는 마지막 **시도**를 담습니다.

### 공시 재무를 붙일 때

```
FilingService.find(symbol)
  ETF 면 건너뜀
  6자리 코드 → DartFinancialService      그 외 → EdgarFinancialService
      종목코드 → 공시처 번호 (dart_corp_code / sec_cik, 비어 있으면 매핑 파일을 받아 채움)
      원재료 숫자만 꺼냄 (연간 3개년 + 올해 누적 + 주식수)
  → CompanyFinancials 에서 비율 계산 (나라 공통)
  → 결산일마다 토스 일봉 종가 → 과거 PER·PBR
```

계산 기준은 [7장 공시 재무 필드](#공시-재무-apifinancialssymbol)에, 그 기준을 고른 이유는 [결정기록 010](결정기록.md#010-재무는-공시에서-가져온다)에 있습니다.

### 스크린샷으로 종목을 넣을 때 (유료)

```
POST /api/import/screenshot (이미지)
  → 긴 변 2,000px 로 줄임 → Claude 가 이름·수량·평단가를 읽음
  → 이름을 종목코드로 (symbol_master, 오타 허용) → 확신이 낮으면 needsReview
  → 화면의 검수 모달에서 사람이 확인
  → POST /api/manual-holdings (더하기) 또는 PUT (통째로 교체) → manual_holding
```

### 기관 13F 를 받을 때 (매일 07:00, 0원)

```
ThirteenFSyncService (13f-sync 스레드, 겹쳐 돌지 않음)
  1. 기관마다
       SEC 제출 목록 → 13F-HR 원본만, 최근 8분기, 2023년 이후(달러 단위)
       이미 받은 접수번호면 건너뜀          ← 대부분의 날은 기관당 SEC 호출 1번
       새 접수면 파일 목록 → 보유 표 XML → InfoTableParser
           같은 종목 여러 줄(운용역별)을 CUSIP·풋콜 단위로 합침
           비공개 빈 제출(NA/000000000)은 버림
           천 달러 단위로 낸 제출은 달러로 바꿈   ← 평균 단가 < 1달러면
       한 트랜잭션: 보유 줄 → 제출 행 (제출 행이 없으면 다음 날 처음부터 다시)
       8분기 넘는 옛 분기는 지움
     한 기관이 실패해도 나머지는 받음
  2. 아직 모르는 CUSIP 만 OpenFIGI 에 물어 티커를 cusip_ticker 에 남김
     키 없이 10개씩·분당 25번. 한도에 다섯 번 연속 걸리면 오늘은 접고 내일 이어서
```

새 제출을 저장하면 `NewFilingEvent` 를 냅니다. `FilingAlertService` 가 받아 **공개된 지 3일 안**이고 보유가 있으면 텔레그램으로 보냅니다(봇 토큰이 없으면 꺼짐). 받기와 알림을 이벤트로 떼어서 텔레그램이 죽어도 받기는 계속됩니다. 피드(`/feeds/13f.xml`)는 이벤트가 아니라 DB 에서 바로 만들고(최근 20건, 1시간 캐시), 알림과 같은 글(`FilingAlerts`)을 씁니다.

조회(`/api/institutions/**`)는 DB 만 읽습니다. 바깥을 부르지 않아 빠르고, SEC 가 막혀도 받아 둔 분기는 보입니다.

### 토큰을 꺼낼 때 (2단 캐시)

```
메모리 → 없으면 MySQL(풀어서) → 없으면 증권사에 발급 요청 → 양쪽에 저장(MySQL 에는 암호화해서)
401 을 받으면 양쪽에서 지움 → 다음 호출에서 새로 발급
```

토큰을 DB 에도 두는 건 재시작할 때마다 새로 발급받으면 증권사 호출 한도에 걸리기 때문입니다 → [결정기록 007](결정기록.md#007-토큰을-db에-저장한다)

DB 에는 `TokenCipher` 가 AES-256-GCM 으로 암호화한 값(`enc:v1:...`)이 들어갑니다. 키는 환경변수 `TOKEN_ENCRYPTION_KEY` 에만 있어서 DB 덤프만 새어서는 토큰을 못 씁니다. 증권사·계정을 암호문에 묶어 다른 행으로 옮겨 붙이면 안 풀립니다. 못 풀면(키 변경·변조) 새로 발급받고, 키가 없으면 평문으로 저장하며 기동 때 경고합니다.

### 공시 재무 (`/api/financials/{symbol}`)

기업분석 프롬프트의 [공시 재무] 블록에 **그대로 들어가는 값**입니다. 분석 전에 0원으로 확인하는 용도입니다. ETF 는 404 입니다.

| 필드 | 기준 |
|---|---|
| `per` | 현재가 ÷ **최근 4분기** EPS (작년 연간 + 올해 누적 − 작년 같은 기간 누적). 적자면 `null` |
| `pbr` | 현재가 ÷ **가장 최근 분기말** BPS |
| `eps`, `bps`, `roe` | **지배주주 몫.** `netIncome` 은 비지배지분 포함 연결 순이익이라 `eps × 주식수` 와 다릅니다 |
| `debtRatio` | 부채 ÷ **자본총계**(비지배 포함) |
| `shareBasis` | 무엇으로 나눴는지. 한국은 보통주+우선주−자기주식(DART), 미국은 토스 발행주식수(없으면 SEC 표지) |
| `history` | 결산일 종가 ÷ 그 해 EPS·BPS. 결산일은 12월로 가정하지 않고 공시에서 읽음. 과거 EPS 도 **지금 주식수**로 나눔 |
| `interim` | 올해 누적. 1년치가 아니라 `roe`·`eps` 를 비움 |
| `annual[].label` | 미국은 결산일을 붙임. `FY2025 (2025-11-02 결산)` |

- DART 는 가장 최근 사업보고서에서 3개년, 그다음 분기·반기 보고서(3분기 → 반기 → 1분기)에서 올해 누적을 꺼냅니다. 연결이 있으면 연결, 지배주주 몫은 전체 재무제표에서 IFRS 계정 ID 로 고릅니다
- EDGAR 는 보고서가 아니라 태그별 사실 목록이라 기간으로 골라냅니다. 태그 이름이 해마다 바뀌어 후보 중 **가장 최근 기간까지 있는 것**을 씁니다(브로드컴 순이익: `NetIncomeLoss` → `ProfitLoss`)
- 토스가 막히면 현재가가 없어 `per`·`pbr`·`history` 만 빕니다

### 기관 포트폴리오 (`/api/institutions`)

SEC 13F 공개 자료입니다. 내 계좌와 무관하고 누구에게 보여줘도 됩니다. 읽는 법을 모르면 틀리게 읽기 쉬운 것들입니다.

| 필드·성질 | 뜻 |
|---|---|
| `weightPercent` | 그 기관 **13F 합계 대비**. 13F 에는 미국 상장 주식·옵션만 들어가서 기관 전체 자산 대비가 아님. 국민연금이면 "미국 주식 중 몇 %" |
| `period` / `filedDate` | 분기말 기준 보유. 공개는 분기말 뒤 **최대 45일**. `filedDate` 전에는 아무도 몰랐던 보유 |
| `putCall` | `PUT`/`CALL` 이면 옵션. 같은 종목 주식과 따로 나옴 (반대 방향일 수 있어서) |
| `ticker` 가 null | OpenFIGI 가 못 찾았거나(채권·워런트) 아직 안 물어봄. 회사 이름은 항상 있음 |
| 정정본 | 13F-HR/A 는 안 받음. 원본만 |
| 노르웨이 중앙은행 | 1·3분기는 비공개 빈 제출이라 2·4분기만 나옴 |
| `/{cik}/changes` | 그 분기와 **보유가 있는 바로 앞 분기**의 비교. `previousPeriod` 를 꼭 볼 것(노르웨이는 반년 전과 비교됨). 주식 수 기준이고 옵션은 뺌 |
| `kind` | `NEW`·`ADDED`·`REDUCED`·`SOLD_OUT`, 그리고 `SPLIT`: 주식 수가 흔한 분할 비율(2·3·4·5·10·20배…)에 딱 맞고 비중이 거의 그대로라 액면분할로 본 것. 매수·매도로 세지 않음 |
| `/overlap?h=AAPL:30,NVDA:20` | 내 포트폴리오와 기관마다의 겹침 = Σ min(내 비중, 기관 비중). 내 비중은 입력 합계를 100% 로 맞춤. 티커 표기(brk-b·BRK.B)는 맞춰 비교. **입력은 저장하지 않음**(GET 이라 주소 공유로 같은 결과). 50종목까지, 모양이 틀리면 400. `/{cik}/overlap` 은 같이 가진·나만 가진·그 기관에만 있는 상위 종목 |
| `/consensus` | 같은 석 달에 **두 곳 이상**이 늘린(`bought`)·줄인(`sold`) 종목. 바로 앞 분기와 비교할 수 있는 기관만 셈(`compared`). 분기는 기관 절반 이상이 낸 가장 최근 것. 사실을 세기만 할 뿐 따라 사라는 뜻이 아님 |
| 단위 | 전부 달러. 천 달러로 낸 곳(듀케인)은 받을 때 바꿈 |

### 실패 응답

전부 `{ "error": "..." }` 한 모양이고 사람이 바로 조치할 수 있는 한국어입니다. 증상별 해결은 [운영 - 장애 대응](운영.md#장애-대응)에 있습니다.

## 8. 기업분석이 만드는 것

```
앱이 확정 (LLM 이 못 건드림)
  수량·평단가·현재가·손익·수익률·비중(항상 합산 기준)·변동성·ETF 여부·레버리지
  개별 기업이면 공시 재무 + PER·PBR·과거 배수
        │  "이건 사실이다. 다시 계산하지 마라"
        ▼
Claude 가 조사 (웹검색 + 출처 필수)
  컨센서스·전망·산업 동향·사업 구조
        ▼
판정 + 7개 섹션 + 리스크 → 스키마 검증 → MySQL
```

- 판정은 `ADD` / `HOLD` / `TRIM` / `EXIT` / `UNCLEAR`. 종목 의견이 아니라 **내 보유 상태**에 대한 판정이라 비중·평단가가 다르면 답이 달라집니다. 정의에 없는 값이 오면 서버가 "판단 보류" 로 떨어뜨립니다 → [결정기록 009](결정기록.md#009-판정을-내린다-단-내-계좌를-전제로)
- 프롬프트는 `src/main/resources/prompts/` 의 `.md`·`.json` 입니다. 분석 내용을 바꾸려면 자바가 아니라 그 글을 고칩니다
- 뉴스 인사이트는 분석용 모델이 아니라 하쿠 4.5(`anthropic.news-model`)로 부르고, 종목당 하루 한 번만 만듭니다(메모리 캐시)

| 공용 | `public/tokens.css` | 색·간격·글자 크기 토큰. 두 영역이 같이 씀 (내 화면 CSS 는 로그인 뒤라 공개 화면이 못 읽어서 따로 뗌) |
| 내 영역 | `portfolio.html`·`portfolio.css`·`portfolio.js` | 내 잔고, 드로어(기업분석·차트·뉴스) |

공개 화면은 GET 만 부르고, 바깥 글자(회사 이름 등)는 `esc()` 를 거쳐 넣습니다. 외부 의존성은 글꼴(Pretendard)과 내 화면의 차트 라이브러리(CDN)뿐이고, CDN 이 막혀도 기본 글꼴로 동작합니다.

- 서버와는 JSON 으로만 이야기합니다. `fetch` 가 자바의 `RestClient` 역할입니다
- 종목을 누르면 **드로어**가 열립니다(데스크톱은 오른쪽, 휴대폰은 아래). 안에서 기업분석 / 차트 / 뉴스 탭. 모서리를 끌어 크기를 바꾸고 `localStorage` 에 기억합니다
- 표는 다섯 줄만 보이고, 700px 이하에서는 카드로 바뀝니다. 좁은 화면 대응은 CSS 로만 합니다
- 차트는 일봉 200봉을 받아 80봉을 보여주고 이동평균선 5·20·60·120
- 색은 전부 `:root` 변수를 거치고 어두운 화면은 변수만 바꿉니다. 빨강·파랑은 등락만 뜻합니다 → [결정기록 008](결정기록.md#008-색은-빨강과-파랑뿐이고-등락만-뜻한다)

화면을 고칠 때의 규칙(글자 크기, 대비, 키보드 접근, 드로어 `inert` 등)은 [CLAUDE.md](../CLAUDE.md#화면을-고칠-때)에 있습니다.

## 10. 안전장치

- 공개 영역에는 13F 같은 공개 자료만 있고, 내 잔고·판정·유료 버튼은 로그인 뒤에 있습니다

- **주문 API 를 부르는 코드가 없습니다**
- `.env` 는 `.gitignore` 에 있고, 토큰과 키는 로그·화면에 전체가 찍히지 않습니다
- 증권사 토큰은 DB 에 암호화해서 넣습니다. 푸는 키는 DB 밖(환경변수)에만 있습니다
- 클로드가 만든 글은 화면에 넣기 전에 HTML 특수문자를 막고, 출처는 `http(s)` 일 때만 링크로 만듭니다
- 환율을 못 구하면 계산을 포기합니다(1 로 대신하지 않음) → [결정기록 005](결정기록.md#005-환율을-못-구하면-예외를-던진다)
- 재분석이 실패해도 이전 성공 분석을 지우지 않습니다
