# 운영

세팅부터 실행, 테스트, 장애 대응까지입니다. 실무의 런북처럼 **순서대로 따라 하거나 증상으로 찾는** 문서입니다.
구조 설명은 [아키텍처](아키텍처.md), 앞으로 할 일은 [로드맵](로드맵.md)에 있습니다.

## 1. 준비물

| | 어디서 |
|---|---|
| Java 21 | Eclipse Temurin 등 (도커로만 돌리면 필요 없음) |
| MySQL 8 | 로컬 설치 또는 도커 |
| Docker Desktop (선택) | 이미지로 돌릴 때 |
| 토스증권 Open API 키 | 토스증권 WTS → 설정 → Open API |
| 나무증권 NAMUH PLUG 키 | <https://www.nhplug.com> (사용신청 필요). 구형 mynamuh.com OpenAPI 는 윈도우 DLL 방식이라 못 씀 |
| Claude API 키 | <https://console.anthropic.com> |
| DART 키 (선택) | <https://opendart.fss.or.kr> → 인증키 신청. 무료, 40자리 |
| SEC 연락처 (선택) | 발급 없음. "앱이름 이메일" 한 줄 |

DART·SEC 가 없어도 앱은 뜹니다. 없으면 기업분석의 재무를 클로드가 웹에서 찾고, 넣으면 공시 원본으로 바뀝니다.
메이븐은 설치 안 해도 됩니다. 저장소에 `mvnw` 가 있습니다.

## 2. 키 넣기

```bash
cp .env.example .env     # 값을 채웁니다. .env 는 .gitignore 에 있어 커밋되지 않습니다
```

- `SEC_USER_AGENT` 는 키가 아니라 SEC 가 요구하는 연락처입니다. "앱이름 이메일" 형식이 아니면 403 입니다
- 계좌 번호(`TOSS_ACCOUNT_SEQ`, `NAMUH_ACCOUNT_NO`)는 **처음엔 비워두고** 5장에서 채웁니다

### 토스 허용 IP 등록

건너뛰면 토스가 전부 403 입니다. 토스증권 WTS → 설정 → Open API → **허용 IP 관리**에 지금 공인 IP 를 넣습니다.
내 IP 는 <https://ifconfig.me>, 앱을 띄운 뒤라면 403 에러 메시지가 직접 알려줍니다.

> 목록이 비어 있으면 전부 통과하지만 하나라도 등록하면 등록된 것만 통과합니다. 학교 망은 하루에 한 번꼴로, 휴대폰 핫스팟은 30분 안에도 바뀝니다.

## 3. 실행 — 도커 (권장)

앱과 MySQL 을 같이 띄웁니다. DB 를 따로 설치할 필요가 없습니다.

```bash
docker compose up -d --build     # 첫 빌드 2~3분
docker compose logs -f app       # "Started PortfolioApplication" 이 보이면 준비 완료
docker compose down              # 끄기. DB 데이터는 볼륨에 남음
```

- 앱 설정은 `.env` 를 그대로 읽습니다. DB 주소만 compose 가 `mysql` 서비스로 덮어씁니다
- DB 데이터는 `mysql-data` 볼륨에 있습니다. 지우려면 `docker compose down -v`
- 로컬에 이미 MySQL 이 3306 을 쓰고 있어도 됩니다. 컨테이너 MySQL 은 바깥으로 포트를 열지 않습니다

## 4. 실행 — jar 직접

```sql
CREATE DATABASE portfolio DEFAULT CHARACTER SET utf8mb4;   -- 테이블은 앱이 만듭니다
```

```bash
./mvnw.cmd -DskipTests package
java -jar target/portfolio-0.0.1-SNAPSHOT.jar
```

- **`mvnw spring-boot:run` 은 쓰지 마세요.** 경로에 한글(`주식`)이 있으면 클래스패스가 깨집니다
- 정적 파일도 jar 안에 있어서 css·js 만 고쳐도 다시 빌드하고 재시작해야 합니다

## 5. 처음 띄운 뒤 할 일

1. **계좌 번호 고정**: `GET /api/toss/accounts`, `GET /api/namuh/accounts` 에서 값을 보고 `.env` 에 적은 뒤 재시작. 안 적어도 앱이 고르지만 호출이 줄고 계좌가 고정됩니다. 나무는 `acct_type` 이 `01` 인 계좌만 주식 잔고가 나옵니다
2. **화면 확인**: <http://localhost:8080>. 표가 뜨면 성공. 서버 상태는 <http://localhost:8081/actuator/health> 가 `{"status":"UP"}`
3. **공시 재무 확인 (0원)**: `GET /api/financials/005930`(DART), `GET /api/financials/AVGO`(SEC). 첫 호출은 매핑 파일을 받느라 10초쯤 걸립니다. `annual` 3개년, `ttm`, `history` 가 나오면 정상
4. **종목 마스터 받기**(스크린샷 등록을 쓸 때): `POST /api/symbols/refresh`. 약 15,000건, 2분 30초

돈이 나가는 주소는 셋입니다(분석·스크린샷·뉴스 인사이트). 비용은 [아키텍처 - API 계약](아키텍처.md#돈이-나가는-주소)에 있습니다.

## 6. 테스트와 CI

```bash
./mvnw.cmd test      # 69개. 외부 API·DB 를 안 불러 키 없이 돕니다
```

PR 을 열거나 `main` 이 바뀌면 GitHub Actions(`.github/workflows/ci.yml`)가 같은 테스트를 돌리고 도커 이미지까지 빌드합니다. 실패하면 PR 에 빨간 X 가 뜹니다.
CI 에는 비밀값이 필요 없습니다. 테스트가 바깥을 부르지 않게 만들어 뒀기 때문입니다.

### 변경을 합치는 법 (PR)

`main` 은 보호돼 있습니다. **직접 푸시와 강제 푸시가 막혀 있고, 관리자도 예외가 아닙니다.**

```bash
git switch -c feat/무엇을-하는지         # 1. 브랜치
# ... 고치고 커밋 ...
git push -u origin HEAD                  # 2. 푸시
gh pr create --fill                      # 3. PR
gh pr checks --watch                     # 4. CI 두 개(테스트와 패키징, 도커 이미지 빌드)가 초록인지
gh pr merge --squash                     # 5. 스쿼시 병합. 브랜치는 자동으로 지워짐
git switch main && git pull              # 6. 로컬 main 맞추기
```

| 규칙 | 왜 |
|---|---|
| CI 두 개가 통과해야 병합 | 깨진 코드가 `main` 에 못 들어감 |
| 브랜치가 `main` 최신이어야 병합 | 각자는 통과해도 합치면 깨지는 경우를 막음 |
| 스쿼시 병합만, 선형 이력 | PR 하나가 커밋 하나. 되돌릴 때 PR 단위로 |
| 리뷰 승인 0명 | 혼자 하는 프로젝트라 자기 PR 을 승인할 수 없음. 팀이면 1명 이상으로 |

저장소는 공개입니다. 커밋·PR·이슈에 실제 잔고, 계좌, 키, IP 를 쓰지 마세요. 2026-09-30 공개 전에 이력을 한 커밋으로 정리했습니다.

## 장애 대응

증상으로 찾으세요. 전부 실제로 겪은 것들입니다.

| 증상 | 원인 | 조치 |
|---|---|---|
| 토스만 403 | 허용 IP 가 바뀜 | 에러에 적힌 IP 를 토스에 등록 |
| 표는 뜨는데 가격이 다 빔 | 토스가 막혀 시세가 없음 | 위와 같음 |
| 토스 429 | 호출 한도 | 잠시 대기. 계좌 번호를 `.env` 에 고정 |
| 재시작 직후 토스 401 한 번 | DB 에 둔 토큰이 만료 | 한 번 더 부르면 새로 발급 |
| 나무 403 (키는 맞음) | Content-Type 에 charset | 코드에서 처리됨. 다시 나면 아래 |
| 나무 11165 | 계좌 유형이 틀림 | `acct_type` 이 `01` 인 계좌 |
| 앤트로픽 400 | 크레딧 잔액 없음 | console.anthropic.com 에서 충전. 재시작 불필요 |
| 앱이 안 뜸 | MySQL 꺼짐 / DB 없음 | MySQL 켜고 `portfolio` DB 만들기 |
| 빌드는 되는데 실행 안 됨 | 경로에 한글 + `spring-boot:run` | jar 로 실행 |
| 빌드 중 `Unable to rename ... .jar` | 앱이 아직 떠 있음 | java 프로세스 종료 |
| `/api/financials` 404 | ETF 이거나 키·연락처 없음 | 아래 "공시 재무" |
| 공시 재무는 나오는데 PER·PBR 만 빔 | 토스가 막혀 현재가 없음 | 토스 403 조치 |
| 차트가 안 뜸 | CDN 차단 / 봉 부족 | 아래 |
| 해외 주식 평가금액이 비정상적으로 작음 | 환율 실패 | 지금은 계산을 포기하고 이유를 띄움 |

### 토스 403 — 허용 IP

가장 자주 겪습니다. 토스가 막히면 **모든 종목의 시세**가 안 옵니다. 시세를 토스에서만 받기 때문에 나무 종목도 가격이 빕니다. 앱 자체는 계속 뜨고 나무 잔고는 보입니다.
에러 메시지가 지금 공인 IP 를 직접 알려주니 그 값을 등록하면 됩니다. 근본 해결은 고정 IP 서버입니다.

### 토스 429 — 호출 한도

계좌 목록을 연달아 부르면 걸립니다. `TOSS_ACCOUNT_SEQ` 를 적어두면 계좌를 매번 조회하지 않습니다.
종목 마스터를 받을 때 시장 일곱 개를 연달아 부르면 **나스닥과 코스닥이 에러 없이 통째로 빠졌습니다.** 그래서 시장 사이에 3초씩 쉽니다.

### 나무

- **403 인데 키는 맞음**: `application/x-www-form-urlencoded;charset=UTF-8` 이면 게이트웨이가 거부합니다. 스프링은 charset 을 끄는 설정이 없어 폼 문자열을 직접 만들어 바이트로 보냅니다
- **성공인데 코드가 00000 이 아님**: 잔고 조회는 `00166` + "조회가 완료되었습니다" 로 옵니다. 코드가 아니라 데이터가 왔는지로 판단합니다

### 클로드

- **400 크레딧 부족**: 키는 정상이고 잔액만 없습니다
- **`fromEnv()` 를 쓰면 안 됩니다**: 이 앱은 `.env` 를 System Property 로 넣습니다. `fromEnv()` 는 OS 환경변수와 로그인 프로파일을 봐서 키를 못 찾거나 **다른 개인 계정으로 과금될 수 있습니다**
- **분석 내용이 이상함**: 자바가 아니라 `src/main/resources/prompts/company-analysis-system.md`(규칙)와 `company-analysis-schema.json`(형식)을 고치고 재시작합니다
- **모델이 "클로드 코드 CLI" 로 나옴**: 2026-09-21 에 크레딧 없이 CLI 로 같은 프롬프트를 돌려 넣은 분석입니다. 공시 재무를 붙이기 전이라 재무는 웹 조사 기준입니다. "다시 분석" 을 누르면 덮어씁니다(유료)

### 공시 재무가 안 붙음

먼저 0원 미리보기(`GET /api/financials/{코드}`)로 봅니다. 404 면 로그에 이유가 찍힙니다.

| 로그 | 원인 | 조치 |
|---|---|---|
| `DART 고유번호가 없습니다` | ETF·리츠, 새로 상장한 종목 | ETF 는 정상. 새 종목이면 `POST /api/financials/mappings/refresh` |
| `SEC CIK 가 없습니다` | ETF (SOXL, SPYI 등) | 정상 |
| `DART 오류 010` / `011` | 키가 틀림 | `DART_API_KEY` 확인 |
| `DART 오류 020` | 하루 2만 건 초과 | 다음 날. 분석 한 번에 8건 안팎이라 보통 안 걸림 |
| `SEC EDGAR 티커 매핑 응답을 받지 못했습니다` | `SEC_USER_AGENT` 없음·형식 틀림 | "앱이름 이메일" 로 넣고 재시작 |

**키가 없으면 로그 없이 조용히 건너뜁니다.** 키가 없어도 분석은 웹 조사로 돌아야 해서 일부러 그렇게 했습니다.

- **PER 이 증권사 앱과 다름**: 기준이 다릅니다(최근 4분기·지배주주·보통주+우선주). 응답의 `shareBasis` 를 보세요. 버그가 아닙니다
- **`history` 가 비어 있음**: 토스가 막혔거나 상장한 지 얼마 안 돼 결산일 주가가 없습니다. 없어도 분석은 돕니다
- **미국 종목의 매출·순이익만 빔**: 회사마다 태그가 다릅니다(은행·보험은 매출 태그가 다름). `EdgarFinancialService` 의 후보 목록에 태그를 추가하세요. 태그는 `https://data.sec.gov/api/xbrl/companyfacts/CIK{10자리}.json` 에서 찾습니다

### 차트가 안 뜸

"차트 라이브러리를 불러오지 못했습니다" 면 CDN 이 막힌 것입니다. 이 앱의 유일한 외부 의존성이라 차트만 영향을 받습니다.
"차트를 그릴 데이터가 부족합니다" 면 상장한 지 얼마 안 됐거나 거래가 없는 종목입니다. 120일선은 121번째 봉부터 그려집니다.

### 뉴스가 엉뚱하게 나옴

종목코드가 아니라 이름으로 검색합니다. 예전에 "현대차" 로 삼성전자 기사가 나왔는데, `uri(String)` 이 URL 을 한 번 더 인코딩해 한글이 `%25EA...` 로 깨진 탓이었습니다. 지금은 `uri(URI.create(url))` 로 고쳐져 있습니다.

### 스크린샷에서 종목을 못 찾음

종목 마스터가 비어 있을 수 있습니다. `GET /api/symbols/status` 로 건수를 보고(약 15,000 이 정상) 적으면 `POST /api/symbols/refresh`.
이름이 비슷한 다른 회사로 가는 건("삼송전자" → 삼영전자) 고칠 수 없는 한계라, 확신이 낮으면 노랗게 표시하고 사람이 확인합니다.

환율이 1 로 계산된 경우였습니다($136 → 136원). 지금은 환율을 못 가져오면 계산을 포기하고 이유를 띄웁니다 → [결정기록 005](결정기록.md#005-환율을-못-구하면-예외를-던진다)
