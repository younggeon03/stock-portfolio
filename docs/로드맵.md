## 목표

**증권사 IT 실무와 닮은 경험을 이 프로젝트로 쌓는다.** 기능을 늘리는 것보다 배포하고, 운영하고, 장애를 겪고 고치는 경험이 목표입니다.

증권사 IT 가 중요하게 보는 건 화려한 기능보다 세 가지입니다. 단계마다 이 셋 중 무엇을 연습하는지 적었습니다.

| | 뜻 | 이 프로젝트에서 |
|---|---|---|
| **틀리지 않는다** | 숫자가 정확하고 검증된다 | 앱이 계산한 숫자, 공시 원본, 대사(잔고 맞춰보기) |
| **멈추지 않는다** | 바깥이 죽어도 버틴다 | 외부 연동 실패 격리, 재시도, 헬스체크, 자동 롤백 |
| **추적된다** | 무슨 일이 있었는지 남는다 | 로그, 지표, 알림, 장애 기록, 결정기록 |

### 선을 그어둔 것

- **판정·적정가는 나만 봅니다.** 불특정 다수에게 종목별 매매 의견을 주면 유사투자자문업 신고 대상일 수 있습니다. 정확한 범위는 공개 전에 확인합니다
- **남의 증권사 키를 보관하지 않습니다.** 사용자마다 자기 토스 설정에 서버 IP 를 등록해야 하고, 토큰 하나로 24시간 계좌를 볼 수 있습니다 → [결정기록 004](결정기록.md#004-증권사-로그인을-포기하고-스크린샷으로-우회한다)
- **주문 기능은 만들지 않습니다** → [결정기록 001](결정기록.md#001-주문-api를-만들지-않는다)

그래서 방향은 둘입니다. **개인 앱은 나 혼자 쓰되 실제로 배포해서 운영**하고(1~4단계), 사람을 모으는 건 **공시 재무를 사실만 보여주는 공개 페이지로 따로 뗍니다**(5단계).

## 2단계. 배포와 자동 배포(CD)

| | |
|---|---|
| 할 것 | 클라우드 서버에 도커로 배포, `main` 에 합치면 자동 배포, 헬스체크 실패 시 이전 이미지로 롤백, HTTPS |
| 실무 대응 | 무중단·롤백 가능한 배포, 운영 환경과 시크릿 관리 |
| 끝났다는 기준 | 코드를 합치면 사람 손 없이 서버가 바뀌고, 일부러 깨뜨린 버전은 자동으로 되돌아감 |
| 면접 거리 | 토스 허용 IP 가 하루에 한 번꼴로 바뀌는 불편을 **고정 IP 서버로 없앴다** |

- [ ] **서버**: 오라클 클라우드 Always Free 가 무료로 고정 공인 IP 를 주는 사실상 유일한 곳입니다(서울 리전). 2026년 6월부터 ARM 이 2코어 12GB 로 줄었고 가입 거절 사례가 있습니다. Render·Railway·Fly.io 는 고정 아웃바운드 IP 가 유료라 답이 아닙니다
- [ ] **이미지 저장소**: GitHub Container Registry(ghcr.io)에 푸시
- [ ] **배포 방식**: GitHub Actions → SSH → `docker compose pull && up -d` → `/actuator/health` 확인 → 실패하면 이전 태그로
- [ ] **시크릿**: 서버 `.env` 는 서버에만. CI 에 필요한 값은 GitHub Secrets
- [x] **토큰 암호화 저장** (2026-10-01): AES-256-GCM, 키는 `TOKEN_ENCRYPTION_KEY`. 서버 `.env` 에 키를 꼭 넣을 것 → [결정기록 007](결정기록.md#007-토큰을-db에-저장한다)
- [x] **헬스체크 주소** (2026-10-01): `/actuator/health/liveness`·`/readiness`(DB 포함)를 관리 포트 8081 에. 자동 배포가 이걸 보고 롤백을 정합니다
- [x] **Swagger 끄는 설정** (2026-10-01): `SWAGGER_ENABLED=false`
- [ ] **앱 전체에 로그인을 건다.** 서버에 올리면 주소만 알면 누구나 내 잔고를 보고 유료 분석 버튼을 누를 수 있습니다. 가장 간단한 건 Caddy 의 basic_auth. `/refresh` 류 관리용 주소도 여기서 같이 막힙니다
- [ ] **HTTPS**: Caddy 나 nginx + Let's Encrypt. 로그인과 같이 해야 비밀번호가 평문으로 안 갑니다
- [x] **스키마 마이그레이션** (2026-10-01): Flyway `V1__init.sql`, Hibernate 는 `validate`. 기존 DB 는 V1 으로 표시만, 빈 DB 는 V1 실행 (둘 다 확인)
- [ ] **DB 백업**: 매일 덤프를 서버 밖으로

> 고정 IP 없이 버티는 방법도 조사해 뒀습니다. 토스 요청만 SSH 터널(SOCKS)로 고정 IP 서버를 거치게 하면 TLS 가 앱과 토스 사이에 유지돼 중간 서버는 암호문만 봅니다(`tossRestClient` 에만 프록시). HTTP 중계를 직접 만들면 `client_secret` 이 중계 서버에 평문으로 보여서 안 됩니다. 토스 허용 IP 는 대역(`/16`) 등록이 안 되고 단일 IP 만 받습니다.

사람이 찾아올 이유가 있는 건 이 부분입니다. 증권사 앱마다 PER 이 다르게 나오는데, 이 앱은 **하나의 기준**(최근 4분기·지배주주·보통주+우선주·결산일 종가)으로 PER 과 과거 PER 범위를 보여줍니다. 현대차처럼 "3년 내내 4~8배를 받던 회사가 지금 11배" 가 한눈에 보입니다.

- [ ] **먼저 확인**: 토스 시세를 남에게 보여줘도 되는지 약관. 안 되면 결산일 종가만 쓰거나 다른 공개 시세로
- [ ] 판정·적정가·내 계좌 정보는 절대 안 나가게 공개용 컨트롤러를 따로 (`/public/**`)
- [ ] 캐시: 공시는 분기에 한 번 바뀌므로 DB·메모리 캐시, 시세는 짧게
- [ ] 호출 한도: DART 하루 2만 건, SEC 초당 10건. 공개하면 우리 쪽 요청 제한(rate limit)이 필요
- [ ] 부하 테스트: nGrinder(국내 회사에서 많이 씀) 또는 k6. 병목 → 개선 → 다시 측정을 기록
